# Detail about included fonts.

Id and version of fonts included and available through
[`use_pkg_gfont`](https://dreamrs.github.io/gfonts/reference/use_pkg_gfont.md).

## Usage

``` r
included_fonts
```

## Format

A data frame with 8 rows and 5 variables:

- id:

  Id for the font.

- family:

  Name of the font.

- category:

  Category.

- version:

  Version number.

- lastModified:

  Last modified date.
